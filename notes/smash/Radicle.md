**Radicle** is a peer-to-peer (P2P), decentralized alternative to traditional platforms like GitHub, designed for managing and collaborating on Git repositories without centralized control. It extends Git by adding a distributed network for source code management, providing developers the ability to collaborate directly with peers instead of relying on a central server.

1. **Decentralized by Design**: Unlike GitHub, Radicle operates without a central server. Developers host their code repositories on a peer-to-peer network, allowing for complete control over their contributions, free from censorship or unilateral restrictions imposed by platforms.

2. **Security and Privacy**: All interactions, including code-sharing and project management, happen securely between peers using cryptographic signatures. This ensures privacy and integrity within the network. There is no single entity that can block or remove repositories.

3. **Git Integration**: Radicle extends Git, making it compatible with existing Git workflows. However, instead of relying on central services like GitHub or GitLab, users clone and share repositories directly within the decentralized Radicle network.

4. **Governance and Funding**: Radicle introduces governance through decentralized autonomous organizations (DAOs) and supports funding projects with Ethereum-based tokens. This allows projects to manage their development and fundraising using blockchain technology. Developers can raise funds directly through the network without intermediaries.

5. **Resilience and Reliability**: Because it is peer-to-peer, Radicle ensures there’s no single point of failure, offering greater reliability. Even if some nodes go down, others can continue to maintain and propagate the project’s code.

For the Smash project, Radicle will be the ideal Git backend, aligning with our [[Smash Values|values]] and the [[Smash Principles|principles]] of decentralization, data ownership, and privacy. It enables contributors to freely collaborate on Smash’s source code, ensuring that no central authority can dictate terms or restrict access to our development repositories.
