The **Backup and Restore** [[Providers|provider API]] in Smash allows users to back up and restore their **[[Peer Identity]]** (excluding PreKeys that are device-specific for each [[Messaging Endpoints]]), **[[Social Graph]]**, [[Profile]], [[Badges]], [[IMProto Messages]], [[Web of Trust]], and other personal data across multiple devices. This protocol also supports **multi-device live sync**, enabling Smash usage across devices.

The Backup and Restore API is designed with decentralization in mind, allowing any **[[Backup Provider]]** to offer unique implementations while remaining compatible with the protocol specifications. Providers can define their own rules, pricing models, and infrastructure, but must adhere to Smash's standardized interfaces for data portability.
